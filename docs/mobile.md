# 移动端与触屏验收

移动端使用现有网站的响应式页面，不另建 App。官网、World 与个人空间编辑器共用现有资源、路由和匿名保存契约。

## 自动检查

```sh
npm test
npm run check
npm run format:check
npm run build
npx playwright test tests/browser/home-mobile.spec.mjs tests/browser/world-mobile.spec.mjs tests/browser/editor-mobile.spec.mjs tests/browser/mobile-save.spec.mjs
```

浏览器项目为 WebKit 和 Firefox，不使用 Chrome。已有开发服务可以通过 `LOOM_TEST_PORT` 指定；测试不应停止其他人的服务。

触屏上下文中的 `tap()` 验证触摸点击；合成 `pointerType: 'touch'` 事件验证多个手指的归属、并发和取消。它们不等同于真机系统级双指缩放、软键盘、浏览器工具栏收放或刘海安全区验收。

## 真机上线前检查

至少使用一台 iPhone Safari 和一台 Android 手机浏览器，分别检查竖屏和横屏。编辑与云端功能使用 HTTPS 预发布站点；局域网明文静态预览不能证明安全 Cookie 和云端保存可用。

- 官网：菜单开关、页面内导航、能力与代码页签、复制按钮；进入 World 再返回时，页面滚动位置与焦点不应丢失。
- World：默认全景、单指转动、双指缩放/平移、视角和环境选项；天气和返回按钮不应遮住彼此。
- 熊猫：场景只保留一只静态屋顶雕塑，位于左侧栅格柱上方，身体与头部均为多面体切面；转动、缩放和切换视角后，双爪仍贴住屋檐，双脚掌贴踩栅格立面，地面没有第二只熊猫，也没有移动/跳跃操控入口。
- 编辑器：布置、空间、对话切换；面板内容滚动；输入空间名、物件数值和对话文字时不应自动放大或让主要操作卡在键盘后。
- 物件：拖动只能由发起的手指控制；第二根手指、触摸取消和失焦不能提交半途移动；双指浏览结束不能误选物件。
- 保存：新增物件后撤销/重做、刷新恢复、导入/导出、保存云端、空间列表；分享页只读，不能出现编辑权限。
- 安全区：底部系统手势条、刘海、地址栏伸缩及短横屏下，主要操作均可到达；页面本身没有横向滚动。
- 回归：桌面鼠标与键盘操作、减少动态效果、WebGL 不可用时的简化浏览仍可用。

这些检查不改变身份规则：不使用浏览器指纹或 IP 识别用户，清除身份 Cookie 后不能认领原云端空间。
