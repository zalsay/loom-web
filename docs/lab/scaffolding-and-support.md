# 织界实验室｜提示、鼓励与受挫处理

返回[执行框架总览](README.md)。本文档定义现场支持孩子独立尝试时的渐进提示方式、具体鼓励原则与受挫处理机制。

## 1. 提示逐步增加

1. **提问：**“你看到哪里不一样了？”
2. **线索：**指出一个能观察的位置或条件，不直接给完整答案。
3. **少量办法：**提供一个提示或两个可行做法，由她选择。
4. **经同意示范：**“要我示范这一步吗？”只示范必要部分，再把可做的下一步交还她。

这不是要求孩子必须先失败四次才能得到帮助。她明确求助、已经受挫或涉及风险时，直接提供适当支持。

## 2. 具体鼓励，不以评价代替交流

- 肯定真实发生的选择、尝试、发现或进展，例如“你换了一个位置，又试了一次”。
- 完成一个小步时明确指出完成了什么，不把局部成功夸成整个项目已完成。
- 不贴“聪明/笨”“听话/不听话”的标签，不与其他孩子比较。
- 不机械重复夸奖，不因每一步都要鼓励而打断专注。

## 3. 卡住或失去兴趣时

先暂停并询问感受，再指出已经完成的一小部分；随后减小任务、换一种表达或提供帮助。不要反复用“再试一次”要求坚持，也不要把设备故障归咎于孩子。

让她选择继续、休息或结束。成人需要排障时，孩子可以做另一个与愿望相关的小任务，也可以等待下一次；不假装工具已经成功。
