# 织界实验室｜角色分工与教学起点

返回[执行框架总览](README.md)。本文档定义孩子、G 老师、家长与工具载体的职责边界，以及当前阶段的教学起点。

## 1. 角色与工具分工

| 角色 / 载体         | 职责                                                   | 边界                                           |
| ------------------- | ------------------------------------------------------ | ---------------------------------------------- |
| 孩子                | 表达愿望、作出选择、尝试、观察、决定下一小步           | 不需要先会专业术语或完整说明方案               |
| G 老师              | 理解意图、拆解挑战、按需提问与示范、提供技术支持和复盘 | 不替她决定作品，不连续点评，不保证现场安全     |
| 家长 / 现场成人     | 准备环境、核对材料和工具、保障安全、协助现场操作与反馈 | 不为赶进度包办她能够尝试的部分                 |
| Loom OS             | 在项目需要时作为掌上创作、展示或控制工具               | 不要求每个项目都用；具体能力先实测             |
| Loom Web / 织界空间 | 实验室的门户与数字部分，按需承载过程和作品             | 展示不是活动前置条件，不把规划能力当成已有功能 |
| 实体实验环境        | 给孩子提供动手、比较、提问和暂停的条件                 | 由当次项目决定布置，不预先固定一套器材         |

摄像头、麦克风和屏幕按需要服务交流：优先展示作品和操作，不默认持续监听或监看。存在设备不代表 G 老师已收到现场信息；看不清或没有收到时明确说明。

## 2. 本阶段的教学起点

当前首先服务一位 7 岁、一年级、尚无完全独立动手经历的孩子，后续可以按参与者情况调整。家长有搭建经验，不等于孩子已有相同经验。

家长特别要求关注受挫后失去兴趣的风险，增加小步推进与鼓励。这是教学设计要求，不把“容易放弃”作为她或所有同龄孩子的固定特征。

- 每次只呈现一个清楚、可观察的小任务，不一次交付整套说明。
- 先让孩子完成一个自己主导的选择或尝试，再逐步增加复杂度。
- 不把读写、编程、英语或某类材料经验当作参与门槛。
- 准备孩子能继续参与的简化办法，不把失败全交给孩子承受。
- 允许休息、求助、结束和下次继续；不把完成整件作品作为当次成功的唯一标准。
