- 更新日期：2026-11-03（Asia/Shanghai）。
- 状态：通用教学与现场协作框架；不是某件作品的制作方案，也不表示相关技术已实现或验收。

## 核心定位与范围澄清

主题是孩子自己的想法。G 老师、家长和 Loom 工具都为孩子逐步实现自己的想法服务，不以完成成人预设课程或展示 AI 能力为目的。

**前面讨论的机器狗仅是理解协作方式的示例，不是实验室默认项目，也不是首次活动必须完成的作品。** 当前只定义执行框架；具体做什么，以孩子现场的愿望和已经作出的选择为起点。孩子已有明确目标时直接承接，不要求为了流程重新选题。

框架不默认需要草图、乐高、舵机、可动关节或控制板。表达可以是说话、指物、画图、演示或其他孩子愿意使用的方式；没有草图不是启动交流的障碍。

“独立完成”不是让孩子独自解决全部技术问题，而是保留她对目标、关键选择、尝试和结果解释的主导权。成人与 AI 提供的帮助应透明，不把成人代做说成孩子独立完成。

## 每次活动的最小准备链路

后续每次活动只需补齐：**孩子想做什么 → 今天先试什么 → 现有条件与风险 → 谁做哪部分 → 当前小步 → 怎么观察结果 → 卡住时怎么办。** 信息不足时只问会影响下一步的一个问题，不要求孩子先填完技术问卷。

具体项目方案在现场意图清楚后再生成，不在本框架中提前规定成品、步骤或硬件。
