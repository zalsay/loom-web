# 织界实验室｜家长幕后准备卡（通用模板）

对应[通用执行框架](../README.md)与[现场执行循环](../session-flow.md)。现场根据孩子当下的想法填写，不默认作品、材料、设备、动作或成品。能直接口头确认的内容不必为了填表反复问孩子。

## 1. 当次活动只确认这些

| 项目                                 | 当次记录 |
| ------------------------------------ | -------- |
| 孩子自己的愿望或表达                 | ＿＿＿＿ |
| 她最在意的部分                       | ＿＿＿＿ |
| 今天她愿意先试的一个小目标           | ＿＿＿＿ |
| 现有材料/工具，以及已经验证能做的事  | ＿＿＿＿ |
| 孩子可以做的部分                     | ＿＿＿＿ |
| 成人必须完成或陪同的部分             | ＿＿＿＿ |
| 当前第一个小步与可观察的结果         | ＿＿＿＿ |
| 卡住时的简化办法或替代活动           | ＿＿＿＿ |
| 停止条件与安全处理（按当次项目确定） | ＿＿＿＿ |

不确定时区分“孩子说的”“我们观察到的”和“我们猜的”。不要把之前示例里的器材或目标直接带入本次记录。

## 2. 成人提前准备

- 先理解孩子已有的选择，再准备少量当前用得到的材料，不摆满全部选项。
- 核对当次工具和风险；有设备操作时先验证，不把现场变成长时间排障。
- 可以准备可靠基础或必要工具，不替她完成关键创作选择。
- 明确哪些需要停机、断电、成人代做或其他措施；仅在相关项目中加入对应安全步骤。
- 不用每次都接摄像头、掌机或网页；不需要的设备不占用孩子注意力。
- 把未实现的能力、缺少的条件和可选替代说明白，不预先承诺完整成品。

## 3. 现场带领顺序

1. **承接想法。** “你想让它是什么样，或者做到什么？”已经说清时直接复述，不重新选题。
2. **选一个小目标。** “今天想先试哪一部分？”只拆小，不偷换她的愿望。
3. **只给当前一步。** 用一句话说明要试什么、怎么看结果；必要时示范一小部分。
4. **留出动手时间。** 专注时少插话；孩子需要时再请 G 老师参与。
5. **先听她观察。** “你看到什么变化？”可以指给我们看，不要求完整报告。
6. **由她决定下一步。** 再试、改一处、请帮忙、休息或结束都可以。
7. **保存真实进展。** 说清今天做到了什么、什么还没完成，下次可以从哪里接着来。

30～45 分钟只是首次预约参考，可提前结束；约 2～5 分钟一个小步只是备课参考，不给孩子计时，不强行打断正在投入的尝试。

## 4. 鼓励与提示

**小步成功后：** 用一句短反馈指出真实进展，不夸大成品完成度。例如 `You did it!` 后接“这一小步是你自己完成的”。

**还没做到时：** 按需要给“提问 → 一个线索 → 少量可行办法 → 经同意示范”（详见[提示、鼓励与受挫处理](../scaffolding-and-support.md)）。不要求她先连续失败才允许求助，也不把工具故障当作她的错误。

**已经受挫时：**

1. 先停下，询问感受，不急着讲道理。
2. 指出已经完成的一点，把它保留下来。
3. 缩小当前任务，或问她是否愿意一起做。
4. 允许休息、改天继续；不以再试或做完作为获得表扬的条件。

## 5. G 老师语音提示

完整要求见[框架的语音约定](../voice-and-communication.md)。简单日常短句尽量用英语，关键解释与安全信息用中文；孩子无需用英语回答。

- 开始：`Ready?` / `Let's start.`
- 判断正确：`That's right.`，仅在确实核实后使用。
- 小步完成：`Great!` / `You did it!`，指出具体进展。
- 肯定尝试：`Good try.`，不把未成功说成成功。
- 需要调整：`Not quite. Let's try this.`，只给一个小提示。
- 协助：`Let's do it together.`，先确认她愿意。
- 放慢或休息：`Take your time.` / `Let's take a break.`

一次只选一句，不反复播报。`No, that's wrong.` 不作为判分口头禅；安全制止可直接使用中文，由现场成人立即处理。

## 6. 简短收尾记录

- 她想做：＿＿＿＿
- 她自己选了 / 试了：＿＿＿＿
- 她发现：＿＿＿＿
- 我们提供的帮助：＿＿＿＿
- 还没完成的部分：＿＿＿＿
- 她想下次继续，还是另作选择：＿＿＿＿

不打分，不强制拍摄或展示。记录与素材按已确认的范围保存，公开发布另行确认。

## 7. 使用孩子卡

按实际目标补齐[孩子小步任务卡](session-child.md)，只展示当前一步。可以由家长朗读或改成口头交流，不要求孩子先读完、写完或答完所有栏目。
