# 织界实验室｜通用现场执行循环

返回[执行框架总览](README.md)。本文档定义单次活动的通用推进循环、活动前准备、时间节奏与配套任务卡入口。

## 1. 现场执行循环

> 承接想法 → 选一个小目标 → 确认可试的条件 → 做一小步 → 看结果 → 选择继续、修改或暂停 → 留下发现。

这是可回退、可暂停的循环，不是必须一次走完的课表。

| 环节          | G 老师与家长做什么                                 | 孩子保留的决定                   | 最小输出                       |
| ------------- | -------------------------------------------------- | -------------------------------- | ------------------------------ |
| 1. 承接想法   | 听她说或看她展示，用一句话复述；不虚构未看到的细节 | 想做什么、什么最重要             | 她认可的一句话愿望             |
| 2. 选小目标   | 从愿望里拆出一个能看到结果的小目标，不更换她的主题 | 今天先试哪一部分                 | 一句“今天先试……”               |
| 3. 确认条件   | 成人核对当次材料、工具和风险；必要基础可提前准备   | 在可行范围内选择做法             | 可试的材料与成人操作边界       |
| 4. 做一小步   | 只给当前一步，等待她动手；需要时给提示或经同意示范 | 选择、摆放、操作或表达           | 一次真实尝试                   |
| 5. 看结果     | 先问她看到了什么，区分观察和猜测                   | 描述结果，提出自己的解释         | 一个可说、可指或可演示的发现   |
| 6. 决定下一步 | 给足够少、实际可行的选择，不要求持续重试           | 再试、改一处、求助、休息或结束   | 她选择的下一步                 |
| 7. 收尾       | 帮她保存已有进展，记录一个发现与未完成部分         | 是否讲述、保留什么、下次想做什么 | 简短记录，不强制拍照或公开展示 |

## 2. 活动前：成人准备，不替孩子预选作品

已知想法时提前核对所需条件；现场新提出的想法先做能力与安全判断。来不及准备时，诚实说明今天能试哪一小部分，与孩子商量，不临场冒险实现完整目标。

家长可以准备可靠基础、材料小盒和备用工具，但不预制全部外观、内容或答案。区分孩子可独立操作、需要协助和必须成人完成的事项。

## 3. 一次活动的节奏

- 30～45 分钟可作为首次活动的预约参考，不是最低时长或完成期限；根据孩子状态缩短或分次。
- 约 2～5 分钟一个小步可作备课参考，不计时催促；一个选择也可能很快完成，专注尝试时不强行打断。
- 当前小步结束才邀请下一步，不把整张流程表连续读给孩子听。
- 收尾不以“必须做完”为条件；未完成的项目保持待续，不改写成已经成功。

## 4. 通用执行模板与下一步

- [家长幕后准备卡](templates/session-parent.md)：现场根据孩子的目标填写，不默认器材或作品。
- [孩子小步任务卡](templates/session-child.md)：只呈现当前小步，可口述，不要求填写整张卡。

后续每次活动只需补齐：**孩子想做什么 → 今天先试什么 → 现有条件与风险 → 谁做哪部分 → 当前小步 → 怎么观察结果 → 卡住时怎么办。** 信息不足时只问会影响下一步的一个问题，不要求孩子先填完技术问卷。

具体项目方案在现场意图清楚后再生成，不在本框架中提前规定成品、步骤或硬件。
