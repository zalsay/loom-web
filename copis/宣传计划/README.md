## 以后怎么放

1. **一篇笔记一个目录**：`README.md` 放状态与制作要求，`publish.txt` 只放标题、正文和话题，视频分镜与口播脚本另放。
2. **成片图片放对应笔记的 `images/`**：统一采用 `01-封面.png`、`02-内容.png` 或对应主题命名，禁止创建空素材冒充成品。
3. **制作源码统一收纳到 `project/`**：HTML 模板、自动化渲染脚本、Playwright 依赖放入 `project/`，保持外层交付目录清爽。
4. **修改版本追加明确标识**：如需替换，保留明确更新记录，严禁使用“最终最终版”等模糊命名。
5. **发布状态以台账为准**：草稿暂存、审核中、公开可见以 [04-发布执行与复盘](04-发布执行与复盘/README.md) 实际核验记录为准。
