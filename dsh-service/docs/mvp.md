# MVP 与验收

## 1. 第一版范围

- 一台共享 PWA
- 3～6 个孩子
- 每个孩子一块地
- 语音提问和转写确认
- 1:1 声纹验证
- 单一 Farm Agent
- 公平队列、租约和过期重排
- 安全活动目录和紧急兜底
- DSH 重启后案卷与队列保留

不做：

- 多个 Agent 或 Agent Teams
- 开放集声纹作为唯一身份
- 持续监听、唤醒词或流式 ASR
- Agent 控制物理执行器
- 公开儿童账号系统
- 原始音频长期保存

## 2. 验收项

### 身份

- 选择 A 但由 B 说话时拒绝入队。
- 声纹失败时不出现在任何孩子的回答里。
- challenge 不能重放。
- 孩子 A 的接口无法读取孩子 B 的 case。

### ASR

- 空白、过短、多人声和高噪声录音要求重录。
- 转写必须经过孩子确认才能入队。
- ASR 失败不保留原始音频。

### 队列

- 多个孩子同时提交时按孩子轮询。
- 每个孩子同时只有一个主问题处于 processing。
- 租约过期后问题自动重新排队。
- 重复的 requestId 不重复创建 case。
- 旧 lease 的迟到回答不能发布。

### Agent

- 入队只产生一个合并唤醒。
- Agent 只看到文字和结构化案卷，不看到音频/embedding。
- 未在活动目录中的 `activityId` 被拒绝。
- 紧急或禁止问题不进入普通模型队列。
- Agent 没有任何设备控制或 shell 工具。

### 运行

- DSH 重启后，等待中、处理中和已回答的案卷可恢复。
- ASR/声纹模型未就绪时孩子端显示明确状态，不吞音频。
- Gateway 失败不会把另一个孩子的身份当作默认值。

## 3. 指标

现场先测，不预设营销结论：

- 声纹错误接受率
- 声纹错误拒绝率
- ASR 重说率
- 从停止录音到入队的中位和 p95 延迟
- 每个孩子等待回答的时间
- 每轮合并后 Agent 的输入 token 和处理成本

只有在上述指标稳定后，才增加 1:N 声纹识别、照片观察或更多孩子。
