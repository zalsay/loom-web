# 安全与隐私边界

## 1. 不设置成人逐条审批

正常问题由 Agent 自主回答，不进入“成人批准”状态。Gateway 的中断只用于不可绕过的系统安全和隐私规则：

- 紧急伤害或身体不适
- 农药、除草剂、化肥等化学品
- 明火、带电设备、电池拆装
- 高处、锐器、机械和车辆
- 未知植物入口、饮用或食用来源不明物

这不是成人逐题审批，而是预先配置的系统护栏。

## 2. 活动目录

Agent 只能选择预置 `activityId`：

- 观察叶片颜色
- 观察土壤表面
- 测量一定体积的水
- 比较遮阴和日照
- 记录植物高度和访客数量

目录之外的活动返回安全替代，不由模型自由发明物理操作。活动目录应由场地负责人一次性配置并版本化。

## 3. 紧急路径

紧急词和界面按钮不进入普通队列。Gateway 返回固定安全响应，并触发场地方既有紧急通知流程。Agent 不能保证现场安全，模型输出也不能覆盖这条路径。

## 4. 儿童声纹

儿童声纹属于高度敏感的生物识别信息。上线前至少需要：

- 监护人单独告知和同意
- 明确仅用于现场身份路由
- 本地处理和默认不上传云端
- embedding 加密、访问控制和删除能力
- 不进 Agent 提示词、不出现在 Session 日志
- 支持拒绝声纹并改用头像/地块卡等低保证方式

这里不是法律意见。涉及儿童生物识别信息的采集、跨境传输和保留周期，应由项目方在部署前做合规评估。

## 5. 数据最小化

- 原始音频：内存处理，完成后丢弃
- ASR 文本：进入对应 case
- 声纹 embedding：独立存储，不进入 case
- Agent 历史：只包含问题、观察和回答
- 日志：不记录原始音频、设备令牌、完整 challenge、相似度分数

## 6. 共享 PWA

- 设备 Cookie 只绑定站点设备。
- 每次发言仍需声明并验证孩子身份。
- 不接受请求体传入的任意 `childId` 作为权限依据。
- 回答接口只返回当前已验证孩子自己的 case。
- 对孩子网络隐藏 DSH 根页面、Remote API、终端和设置。
