## 首期交付边界

复用原厂开发板 2 代、舵机和电池。在一个平整、干燥、封闭、摄像头覆盖全程的工位内，低电或 Pad 请求可以启动回窝；鸭子无需人扶正或插线，最终通过原厂充电输入开始充电。只验证单鸭单窝，不做泥地巡航、绕人、远程召回或自动离窝。充电座不是第二套锂电充电器。官方资料：https://shanmaotech.cn/flashduck/#s3 。

现有 duck_look 镜像仅写颈部，不能走；聊天版 walk 没有确定性、抢占和运动反馈，不作为导航执行器。本期另建独立运动固件配置，默认禁用动力，不改变现有颈轴固件。

## 闭环方法

固定俯拍机标定地面坐标，在窝口和鸭背安放不同的视觉标记（例如 AprilTag）。在网关连续取帧，记录采集时间；鸭子每做一次短动作必须先停稳，再次观察位置和朝向。先到宽停车区，调整躯干朝向，使背包上的吸附面靠近支架线头；粗定位靠视觉，最后小偏差由浮动线头被动补偿，不要求脚底或底盘对准凹槽。不得假定磁吸距离，或让鸭子拖着线继续找位。测量最大单步位移、转向误差、步幅分布和失联停止距离，据此确定等待位、视觉误差阈值、走廊宽度及安全余量；不要采用未经测量的固定厘米数。视觉分辨率不够时缩小工位或单设工位摄像头。有人或动物可自由进入的地方不启用自动运动；通用摄像头和模型识别人不是安全联锁。

状态机：`idle → requested → preflight → approach → align → enter → seated → charging_confirmed`。任何阶段可进入 `blocked`，返回可定位的 reason。需要现场处理的故障保持锁定。`charging_confirmed` 不是 `full`。

- 入场授权、位姿新鲜、工位封闭、窝空闲、姿态正常、电量够走回窝，才可进入 approach。低电去抖，保留足够完成回程的电量；更低的临界状态禁止走动并提醒人工回收。没有可靠低电来源时只能验证手动触发的自主归位，不能宣称低电自治。
- 请求绑定 `dockId + bootSession + stepSeq`，每步短租约、一次最多一步；网络丢包只查状态，不盲目重发。旧照片、目标丢失、姿态异常、超时、未观察到进展、网关失联均不再发下一步；鸭端本地必须能在受控时间内结束当前动作，不能只依赖网关发停令。断电/重启后不自动恢复未完成任务。必须有独立、现场可触及的动力切断手段。
- 就位即锁定运动，支持身体后再进入安全动力状态，底座才允许向原板输入供电。稳定观察到经验证的充电证据后才报告充电；接触抖动或就位但未充上则撤销底座供电并报错，不在触点通电时挪动。取消已充电任务不自动离窝。若插电后鸭端下线，状态由独立底座上报；若拿不到可靠充电证据只报“已就位/输入已接通，充电未确认”。

## 座端实体指示灯（头部磁吸方案，待实测）

最新结构以鸭头摄像头观察座端固定标记，头部 Type-C 磁吸头与窝端浮动线头对接为目标；下节背部样件保留为早期备选。座端使用一盏带「充电中」标识的双色灯，设在侧面，避开视觉标记及摄像头近距离反光区域。控制器在本地驱动灯，不依赖 Pad 或 Agent 在线。

| 灯态 | 座端判据 |
|---|---|
| 熄灭 | 空座或已脱开。上电、复位不恢复旧的充电标志。 |
| 黄灯慢闪 | 已检测到接合，正在等待本次对接的充电证据。磁吸、USB 有电或主板运行电流不能单独触发绿灯。 |
| 绿灯常亮 | 接合稳定、无故障，并持续收到本次对接的有效「电池正在充电」信号。绿灯不表示充满。 |
| 黄灯快闪 | 接合后超时未确认、反馈中断或接触异常；撤销绿灯并进入故障流程。检测脱开立即撤销供电与充电灯态。 |

普通两极磁吸线只送电，不附带充电状态。台架先核实二代板原厂充电指示灯或充电状态输出在充电、充满、拔线和未接电池时的不同表现；若原灯可被可靠区分，可用遮光光敏探头读取、无需改电池回路。若不能可靠区分就不亮绿灯。回传若经鸭端网络，绑定本次 dockId 并检查新鲜度，不能把插电后掉线解释为开始充电。已满若有独立可靠信号应另报「已满」，不作为故障或充电中。

## 背部磁吸样件与不通电试验（2026-11-25）

淘宝[瀚方电子 2PIN 磁吸连接器](https://item.taobao.com/item.htm?id=1090539142771)详情页分别选规格：`2PIN磁吸线PH2.8` 显示 ¥4.60，`2PIN磁吸母座带耳PH2.8` 显示 ¥2.60，商品小计 ¥7.20。页面运费 ¥2，未核实合单结算价。线头图注探针间距 2.84 mm，磁吸间距 9 mm 是商品标注，不能当作隔空吸合距离。未证实两项的配对方向、防反接、持续电流与温升、脱开力，也未确认母座附引线或能免焊接原板；先询问店家并取样，勿接电池端子。

用背包空壳和不通电的线头，从不同左右偏移、高度和偏角靠近，记录自然吸正的范围、脱开是否拖倒鸭体、线头是否缠脚。将实测可吸合区域与鸭子停车位置的散布比较；前者覆盖不了后者时先改浮动支架或增加宽口导向，而不是加强磁力或提高舵机推力。磁体与小件必须封装固定。贴合不等于开始充电；接合检测和原厂充电证据分开验证。

## 交付顺序与门槛

1. **硬件闸门**：向厂家确认原板输入电压/电流、充电与充满信号、上电/插电复位行为、是否有可靠低电信号、是否允许边充边运行；验证可独立停动力且不破坏原厂充电保护。达不到就停止对应自动化分支，不猜接线。
2. **无动力桌测**：用人工移动的鸭模、录制的 RTSP 画面和模拟电池/底座信号验证状态机。覆盖遮挡、网断、重启、倒放旧帧、错误鸭/窝、多个 Pad 争抢、信号抖动；验证状态不将“就位”误报成“充电”。用乐鑫 Web 模拟器只测 Pad 意图和状态显示，不能代替本地运动或锂电实测。
3. **有人值守、底座不供电**：在封闭软围栏内从左右偏置及不同朝向起步，测视野、步幅、停稳和人工急停。先验证短动作可中断，不使用原厂阻塞长动作作为急停路径。失败保持静止或人工处置，不让模型自行加速或试其他动作。
4. **值守充电验证**：建议试点门槛为 20 次不同初始位姿至少 18 次无需干预且确认进入充电；其余必须安全停机并报告原因。每项故障注入均须通过，且危险接通、越界、充电时运动、重启后继续走均为零容忍。记录回窝用时、误差、就位未充次数；这些是建议验收目标，不是已有性能。成功后再评估是否扩展场地，不能据此宣称可无人值守。
